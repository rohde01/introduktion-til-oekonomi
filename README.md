# Introduktion til økonomi

Københavns Universitet · BSc i datalogi-økonomi · Efterår 2022, blok 2 · 7,5 ECTS  
Kursuskode NMAA04032U · [Kursusbeskrivelse](https://kurser.ku.dk/course/nmaa04032u)

Introduktion til mikroøkonomisk teori med forbrugervalg, produktion og markedsligevægt, bygget på Varians Intermediate Microeconomics with Calculus. Repoet indeholder mine fire afleveringer og mine noter til øvelserne.

## Indhold

| Mappe | Indhold |
| --- | --- |
| `assignments/aflevering-<n>/` | Afleveringer 1–4, `main.tex` og `main.pdf` |
| `notes/oekonomi-regneark/` | Noter til øvelsesark og øvelser fra bogen |
| `materials/` | Kursets eget materiale. |

## Værktøjer

LaTeX

## Byg

Byg en PDF fra latex igen med:

```bash
tectonic -Z continue-on-errors main.tex
```
